# FlipItNews AI — News Classification

End-to-end NLP project for automated news categorization using BoW, TF-IDF, Word2Vec, an MLP neural network, and a BiLSTM RNN.

## Dataset
The supplied `bbc-news-data.csv` is tab-separated even though its extension is `.csv`. The notebook correctly reads it with `sep="\t"`. It contains 2,225 articles with `category`, `filename`, `title`, and `content`.

## Setup
Python 3.10–3.11 is recommended for broad TensorFlow compatibility.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the notebook
Open `FlipItNews_News_Classification.ipynb` in Jupyter or VS Code and run all cells. It performs EDA, cleaning, model training/evaluation, and saves deployment artifacts under `models/`.

Training can take several minutes depending on CPU/GPU and library versions.

## Run the dashboard
After the notebook has successfully created `models/best_rnn.keras`, `models/tokenizer.json`, `models/label_classes.json`, and `models/config.json`:

```bash
streamlit run app.py
```

## Deploy
Push the project (including the generated `models/` artifacts) to a Git repository and deploy `app.py` on Streamlit Community Cloud, selecting `requirements.txt`.

## Methodology notes
- The vectorizers/tokenizer are fitted on training text only to avoid leakage.
- The RNN uses a sequence-preserving text version; stop-word removal is not applied to this path.
- Results are generated by running the notebook; no model performance numbers are assumed in advance.
- This BBC News dataset is a benchmark dataset for the assignment. Confirm it matches the provided FlipItNews Drive dataset before final submission.
